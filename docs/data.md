# 数据说明（负责人：P1，数据有变动时更新）

## 1. 语料来源

| 项 | 内容 |
|---|---|
| 文本 | 《三国演义》一百二十回（公版书） |
| 版本 | 待填：采用的电子版来源/校勘说明 |
| 规模 | 约 60 万字，120 回 |
| 存放 | `data/raw/`（不入仓库，群共享目录 `语料/`） |

切分规则：按行首 `第X回` 正则切分，回目号按出现顺序编号 1—120；正文不保留页眉页脚。

## 2. 抽取规则

1. **词典匹配**：以 `data/persons.csv` 的姓名与别名为键，在每回正文中计数；
2. **长名优先**：别名按长度降序匹配，避免"刘"抢走"刘玄德"（当前实现见 `scripts/extract_mentions.py`）；
3. **共现定义**：同一回中同时出现即记一次共现，`weight` 按共现次数线性归一化到 1—100；
4. **关系类型**：共现只产生"候选关系"，`type`/`evidence`/`confidence` 全部人工标注；
5. **事件**：人工整理 40 条以上，字段见 `data/README.md`。

## 3. 别名与置信度

- 别名来源：字、号、官职、谥号、俗称（如 玄德 / 卧龙 / 武侯 / 先主）；
- `confidence` 判定（待定稿，用来回答"凭什么给这个值"）：
  - 0.9—1.0：原文直接陈述（"结为兄弟"）；
  - 0.7—0.9：多处情节强暗示（长期同阵营、共同征伐）；
  - 0.5—0.7：同回共现推断，未见明确表述；
  - < 0.5：存疑，保留但在文档中标注。

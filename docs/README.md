| 文档 | 维护人 | 内容 |

| [data.md](data.md) | P1 | 数据来源、抽取规则、抽样质检、已知问题 |

写作约定：

- 每份文档开头写清负责人和更新时机；
- 论文/报告里的章节直接从这些文档改写，不要另起一份；
- 答辩被问到"这个参数为什么这么定"，答案应当能在文档里找到。
